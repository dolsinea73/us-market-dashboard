# 미국 증시 심리 대시보드

## 아이폰 설치
1. 저장소의 **Add file → Upload files**에서 이 ZIP을 풀어 나온 파일과 `.github/workflows/update.yml`을 같은 경로로 업로드합니다. 모바일에서는 폴더 업로드가 어려우므로 PC 사용을 권장합니다.
2. **Settings → Actions → General → Workflow permissions**에서 **Read and write permissions**를 선택합니다.
3. **Actions → Update market data → Run workflow**를 실행합니다.
4. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 선택합니다.
5. https://dolsinea73.github.io/us-market-dashboard/ 로 접속합니다. 최초 배포에는 몇 분 걸릴 수 있습니다.

무료 GitHub Actions 스케줄은 지연되거나 중단될 수 있고 Yahoo/CNN 공개 데이터 접근은 변경될 수 있습니다. 수집 실패 지표는 데이터 없음으로 표시됩니다.
